## Lebanon Driving Quiz

An interactive web application designed to help users prepare for the Lebanese driving license computer examination.

## 📋 Features

- 🌍 Multi-language support:
  - English
  - Arabic
  - French

- ❓ Randomized quiz system
  - Text-based questions
  - Image-based traffic sign questions

- ⏱️ Timed examinations

- 📊 Instant results and score calculation

- 🔒 Access code authentication system

- 📱 Responsive design for desktop and mobile devices

- 🎯 Practice mode that simulates the official Lebanese driving exam experience.

## 📝 How It Works

1. Users enter a valid access code.
2. They select their preferred language.
3. The system generates a randomized exam from the available question bank.
4. Users answer all questions within the allotted time.
5. Results are displayed immediately after submission.
